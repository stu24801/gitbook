# Intelli J Idea 常用快捷鍵

format code : **Ctrl+Alt+L , ⌘+opt+F**

**remove unused lib : CTRL + ALT + O , Ctrl + opt**

**get/set generate : ⌘N (macOS), or Alt+Insert (Windows/Linux)**

search class : dowble shift(windows) , **⌘O**

**close windows  : ctrl + F4 , ⌘W**

To add a new line below the current line, press **Shift+Enter (⌘+shift+Enter)**&#x20;

To add a new line above the current line, press Ctrl+Enter **(⌘+shift+Enter)**

import all lib : **Ctrl+Alt+L , ⌘+opt+I**

{% hint style="info" %}
自動加載缺乏的引入class

Under `Preferences > Editor > General > Auto Import`

Set `Add unambiguous imports on the fly`

Edit: Using this method, when there _are_ ambiguous imports, IntelliJ will let you know, and you can then use Alt + Enter&#x20;
{% endhint %}
